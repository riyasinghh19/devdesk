How to use the SQL formatter

  1. Paste your query into Your SQL. Pasting formats it straight away.
  2. Pick your database so dialect-specific syntax, such as Snowflake's QUALIFY or T-SQL's [brackets], is understood.
  3. Choose keyword case, indentation and where AND/OR go. The output updates as you change them.
  4. Click Copy or download a .sql file. Use Minify when you need the whole query on one line, for example inside a config file.

What formatting changes

Formatting only changes whitespace and the case of SQL keywords. Table names, column names, string values and the logic of your query stay exactly as they were. Here's a small query before and after:

select o.id,c.name,sum(o.amount) total from orders o join customers c on c.id=o.customer_id where o.status='PAID' and o.dt>='2026-01-01' group by o.id,c.name
SELECT
  o.id,
  c.name,
  SUM(o.amount) total
FROM
  orders o
  JOIN customers c ON c.id = o.customer_id
WHERE
  o.status = 'PAID'
  AND o.dt >= '2026-01-01'
GROUP BY
  o.id,
  c.name

Tips for readable SQL

  • One column per line. Diffs in pull requests then show exactly which column changed.
  • Name your CTEs for what they hold. monthly_revenue reads better than t1.
  • Put conditions at the start of the line. Leading AND makes it easy to comment one filter out while debugging.
  • Pick one keyword case and keep it. Most teams use uppercase keywords and lowercase names.
  • Alias every table in a join. Short, meaningful aliases like o for orders stop ambiguity errors.

Frequently asked questions

Is my SQL sent anywhere?

No. Formatting happens in your browser with JavaScript. Your query is not uploaded or stored, which makes it safe for queries that mention internal table names.

Why did I get a "couldn't format" message?

The formatter needs to read the query. An unclosed quote or bracket, or syntax from a different database, usually causes it. Check the database selector first, then look for a missing ' or ).

Will formatting change my query's results?

No. Only spacing, line breaks and keyword case change. The query runs exactly the same.

Can I format several queries at once?

Yes. Separate them with semicolons and they're formatted one after another, with a blank line between each.

What does Minify do?

It removes comments and extra whitespace and puts the whole query on one line, while leaving text inside quotes untouched.
