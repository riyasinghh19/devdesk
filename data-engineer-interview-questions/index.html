Data engineer interview questions

Questions that actually come up in data engineering interviews, with short answers you can explain in your own words. Written by a working data engineer.

How to prepare

  • SQL is round one almost everywhere. Practise window functions, joins on messy data and "find the second highest" style questions until you can write them without looking anything up.
  • Know one cloud stack deeply. For Azure: ADF, ADLS, Databricks or Synapse, Key Vault. Be ready to draw a pipeline you've built.
  • Bring numbers. Data volumes, runtimes, cost savings. "Loaded 2 TB a day" is more convincing than "worked on big data".
  • Practise system design out loud: source → ingestion → storage layers → transformation → serving, plus monitoring, retries and late data.
