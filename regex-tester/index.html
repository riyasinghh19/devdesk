    Regex cheat sheet
    
    
    
      
    PatternMeans
    
      
        
    .Any character except a line break
    
        
    \d \w \sDigit, word character (letter, digit, _), whitespace
    
        
    \D \W \SThe opposite of each
    
        
    [abc] [^abc] [a-z]One of, none of, a range
    
        
    * + ?0 or more, 1 or more, 0 or 1
    
        
    {3} {2,5} {2,}Exactly 3, 2 to 5, 2 or more
    
        
    *? +?Lazy: as few as possible
    
        
    ^ $ \bStart, end, word boundary
    
        
    (…) (?:…) (?<name>…)Capture group, non-capturing group, named group
    
        
    a|ba or b
    
        
    (?=…) (?!…) (?<=…) (?<!…)Followed by, not followed by, preceded by, not preceded by
    
          
    
    
    
    Regex in SQL
    
    
    This tester uses JavaScript regex. Most patterns work the same in SQL, with small differences:
    
    
      
      
    • Snowflake: REGEXP_LIKE(col, pattern) must match the whole string. Use REGEXP_SUBSTR or REGEXP_COUNT to find a part. Backslashes must be doubled inside single quotes ('\\d+'), or use $$\d+$$.
      • 
      
    • PostgreSQL: col ~ 'pattern' (case-sensitive) and ~* (ignore case), or REGEXP_REPLACE.
      • 
      
    • BigQuery: REGEXP_CONTAINS(col, r'pattern'). The r'' raw string avoids doubling backslashes.
      • 
      
    • SQL Server has no regex in older versions; LIKE with [0-9] covers simple cases. SQL Server 2025 adds REGEXP_LIKE.
      • 
    
    
    
    Frequently asked questions
    
    
    Why does my page not freeze on a bad pattern?
    Patterns run in a background worker with a time limit. Patterns like (a+)+$ can take exponential time ("catastrophic backtracking"); the tester stops them after one second and tells you.
    
    
    Is this regex flavour the same as Python?
    Very close. Python uses (?P<name>…) for named groups, while JavaScript uses (?<name>…). Everything else in the cheat sheet works in both.
    
    
    Is my text sent anywhere?
    No. Everything runs in your browser.
