What is epoch time?

Unix epoch time counts the seconds since 1 January 1970, 00:00:00 UTC. It has no time zone: the same number means the same instant everywhere. Time zones only matter when you display it.

The IST gotcha

IST is UTC + 5:30, with no daylight saving. If a timestamp column looks 5½ hours off, the database is showing UTC and you are reading it as IST (or the other way round). In Snowflake, CONVERT_TIMEZONE('UTC', 'Asia/Kolkata', ts) fixes the display.

Frequently asked questions

Why do I get a date in 1970?

You probably passed milliseconds to a function that expects seconds, or the other way round, a very small number. Check the digit count.

What is the year 2038 problem?

Systems that store epoch seconds in a signed 32-bit integer overflow on 19 January 2038 at 03:14:07 UTC. Use 64-bit integers (BIGINT) for timestamp columns.

Are leap seconds counted?

No. Unix time ignores leap seconds, so every day is exactly 86,400 seconds.
