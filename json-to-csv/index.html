JSON to CSV

Paste JSON from an API, a log or a NoSQL export and get a clean CSV you can open in Excel or load into a database. Nested objects become their own columns.

JSON
CSV
Converts as you type.

How the conversion works

  1. Find the rows. If your JSON is a list, each item becomes a row. If it's an object holding a list (like {"data": [...]}), the tool finds that list for you.
  2. Find the columns. Every key that appears in any row becomes a column, in the order it first appears. Missing values are left blank.
  3. Flatten nested data. {"user": {"city": "Pune"}} becomes a column called user.city.
  4. Quote safely. Values containing the separator, quotes or line breaks are wrapped in quotes, following the CSV standard (RFC 4180).

Example

[{"id": 1, "name": "Asha", "address": {"city": "Pune"}, "skills": ["SQL", "Python"]}]
id,name,address.city,skills
1,Asha,Pune,SQL; Python

Tips

  • Opening in Excel? Keep "Excel-friendly download" on. It adds a marker that makes Excel read Hindi, Tamil, ₹ and other non-English characters correctly.
  • European Excel often expects semicolons. Switch the separator if everything lands in one column.
  • Loading into a warehouse? Snowflake COPY INTO and BigQuery load CSV with a header row directly. Or turn the CSV into INSERT statements with CSV to SQL.

Frequently asked questions

Is my data uploaded?

No. Conversion happens in your browser, so it's safe for production data and API responses.

How big a file can it handle?

Tens of thousands of rows work well. Very large files (hundreds of MB) are better handled with a script, for example Python's pandas.json_normalize.

It says my JSON is invalid. Why?

The message shows the line and column. Common causes are single quotes instead of double quotes, a trailing comma after the last item, or comments. JSON allows none of these.

Does it support JSON Lines (one object per line)?

Yes. If the text isn't one JSON value, the tool tries reading each line as its own object.
