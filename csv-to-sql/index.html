What it does with your data

  • Separator is detected from the first line: comma, semicolon, tab or pipe.
  • Quoted fields are respected, including commas and line breaks inside quotes (the CSV standard, RFC 4180).
  • Single quotes in text are doubled (O'Brien → 'O''Brien'), so the SQL never breaks and can't be injected.
  • Numbers stay unquoted only when the whole column is numeric. A column like pin with 0411 stays text so the leading zero survives.
  • Column names are cleaned: spaces and symbols become underscores (First Name → first_name).

When not to use INSERTs

For more than a few thousand rows, bulk loading is much faster: COPY INTO from a stage in Snowflake, \copy in Postgres, LOAD DATA INFILE in MySQL or BULK INSERT in SQL Server. INSERTs are best for seed data, test fixtures and small lookup tables.

Frequently asked questions

Is my CSV uploaded?

No. Everything runs in your browser.

How are dates handled?

Values like 2026-10-31 or 2026-10-31 09:30:00 are recognised and the column type is set to DATE or TIMESTAMP. They are inserted as quoted strings, which every database listed converts automatically.

My CSV has no header row.

Add one line at the top with column names, for example col1,col2,col3.
